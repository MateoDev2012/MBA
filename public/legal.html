Acceptable use

There is a rate limit, and the limit is the only thing standing between a shared free server and Roblox blocking it for everyone. Do not:

  • Run a script, scraper or bot that pulls thousands of requests per minute, or that ignores Retry-After when it gets a 429.
  • Use the API as a general-purpose proxy, or to cache and re-serve Roblox images at scale.
  • Attempt to bypass the rate limit, the badge check, or any other limit on the service.
  • Use it to break the law, to harass anyone, or to distribute malware.

Exceeding the limits may get a single IP throttled. Sustained abuse gets the instance blocked without notice, because the alternative is the whole API going down for everybody.

Privacy

Short version: this service does not want to know who you are, so it does not ask.

  • No accounts, no sign-in, no API keys required, no cookies, no tracking pixels, no analytics, no fingerprinting.
  • The server keeps the standard access log the web server writes: IP address, timestamp, method, path, status. It is used to enforce the rate limit and to find out what is broken. It is not sold and not used for advertising.
  • Responses are cached in memory for 30 seconds (player counts) and 5 minutes (votes) so that popular games are not fetched from Roblox over and over. The cache is shared by everyone, which is part of why there is no per-request cost.
  • Outbound requests carry nothing about you. They are made to Roblox’s own API endpoints with no identifier attached.
