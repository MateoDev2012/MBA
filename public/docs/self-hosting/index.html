Run your own copy

Only for people who want their own deployment. If you don't, just point the script tag at a public instance and skip all of this.

3 steps

Quick start

  1. Clone & install git clone && npm install
  2. Run locally npm start (or npm run dev for auto-reload). Runs on http://localhost:3000.
  3. Set SITE_URL In roblox-stats.js (line ~117) set your domain so the credit badge links somewhere real.

Set SITE_URL before you publish. It ships empty on purpose — with it empty the badge still renders and enforces itself, it just isn't a link yet.

Files

What you actually need

To use the API you need one file: roblox-stats.js (or zero, if you use a hosted instance). The other files in this repository are the server — the part you deploy once so other people can call it.

API keys, if you want them

Out of the box no key is needed. Set API_KEYS in .env to enable three modes:

.env dotenv
# a public key, readable by anyone who has the file
API_KEYS=Made by MoonlightStudios

# off        no key at all (only possible with no keys configured)
# optional   no key works, but a valid key gets a higher limit   <- default
# required   every endpoint answers 401 without a valid key
API_KEY_MODE=optional

RATE_LIMIT_ANON_MAX=30
RATE_LIMIT_KEYED_MAX=600

Callers send it in a header, never in the URL:

fetch('https://your-domain.com/api/v1/games/994732206', {
  headers: { 'X-API-Key': 'Made by MoonlightStudios' }
})

Each key can carry a name and optional domain lock:

API_KEYS=Made by MoonlightStudios;partner-key:AcmeSite:yoursite.com,acme.dev

The bundled SDK and MCP server read ROBLOX_API_KEY from the environment automatically:

ROBLOX_API_KEY=Made by MoonlightStudios

A key here is not a secret, and pretending otherwise would be worse than saying so. It sits in plain text inside a file every visitor downloads, so anyone can read it with view-source. What it actually buys you is a rate limit you control, the ability to revoke one caller without restarting anything, and an optional domain lock (API_KEYS=key:Name:yoursite.com). It does not make the data private, and it is not what keeps this API free to use — the credit badge in roblox-stats.js is. Check what a key can do.

Required

Credit badge

Set SITE_URL in roblox-stats.js

The badge links Moonlight Studios to this URL. It ships empty so you must set it.

// In roblox-stats.js (line ~117)
var SITE_URL = 'https://your-domain.com';

With SITE_URL empty the badge still enforces itself (deleting/hiding it still stops the script), but it won't be a clickable link. Set it before you publish.

Caddyfile caddyfile
your-domain.com {
  reverse_proxy localhost:3000
}

Caddy handles HTTPS automatically. For Nginx, proxy_pass to http://localhost:3000 and add SSL certs.

Verify

Verify your deployment

# Health check (always works, no key needed)
curl https://your-domain.com/health

# JSON index
curl https://your-domain.com/api

# Live game data
curl https://your-domain.com/api/v1/games/994732206

# Script download (forces download)
curl https://your-domain.com/roblox-stats.js?download=1

# Test the script in browser
open https://your-domain.com/test-fix.html

If /health returns {"ok":true} and /api/v1/games/994732206 returns Blox Fruits data, you're live.
