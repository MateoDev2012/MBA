Quick start

Get live Roblox game stats on your page in 30 seconds. No signup, no API key, no build step.

Download roblox-stats.js Browse games
Method 1

Script tag — zero code

Copy roblox-stats.js to your project, add one script tag, and write stat names in {{braces}}.

index.html html
<script>
  window.RBX_GAME_ID = '994732206';  // Your game's universeId
</script>
<script src="https://ms-mba.up.railway.app/roblox-stats.js"></script>

<h1>{{name}}</h1>
<p>{{playing}} players right now &middot; {{likes}} likes</p>
<img data-rbx-set="src=thumbnail:url" alt="Game logo">

That's it. The script finds {{placeholders}}, fetches live data once, and fills them in. No framework, no build step, works on GitHub Pages, Netlify, Vercel, or any static host.

Per-element scope (multiple games on one page)

Put data-rbx-game on any container to scope placeholders inside it.

<div data-rbx-game="994732206">
  <h2>{{name}}: {{playing}} players</h2>
</div>
<div data-rbx-game="1686885941">
  <h2>{{name}}: {{playing}} players</h2>
</div>
Method 2

Plain JSON — any language

Every endpoint is a plain GET with open CORS. Call from browser, server, Python, PHP, anything.

GET https://ms-mba.up.railway.app/api/v1/games/994732206
const res = await fetch('https://ms-mba.up.railway.app/api/v1/games/994732206');
const { data } = await res.json();

console.log(data.name);                 // "Blox Fruits"
console.log(data.playing);              // players online right now
console.log(data.ratings.upVotes);      // likes
console.log(data.creator.name);         // owner
console.log(data.thumbnail);            // logo URL
import { getGame, search } from 'roblox-stats-sdk';

// Point at your own deployment if self-hosted
const game = await getGame(994732206);
console.log(game.name, game.playing, game.ratings.upVotes);

const results = await search('Blox Fruits', { limit: 5 });

Install: npm install roblox-stats-sdk. Set ROBLOX_BASE_URL for custom deployments.

import requests

data = requests.get("https://ms-mba.up.railway.app/api/v1/games/994732206").json()["data"]
print(data["name"], data["playing"], data["ratings"]["upVotes"])
$json = file_get_contents("https://ms-mba.up.railway.app/api/v1/games/994732206");
$data = json_decode($json, true)["data"];
echo $data["name"] . " — " . number_format($data["playing"]) . " playing";
curl https://ms-mba.up.railway.app/api/v1/games/994732206

# Many at once:
curl "https://ms-mba.up.railway.app/api/v1/games/batch?ids=994732206,1686885941"

# Fill template:
curl -X POST https://ms-mba.up.railway.app/api/v1/render \
  -H "Content-Type: application/json" \
  -d '{"universeId":994732206,"html":"{{playing}} players"}'
Method 3

Ready-made card widget

No layout needed. Put an ID in an empty

and get a complete card with banner, logo, and stats.

<div data-roblox-game="994732206"></div>
<script src="https://ms-mba.up.railway.app/roblox-stats.js"></script>

Options

AttributeValues
data-roblox-gameUniverse ID (required)
data-roblox-theme"dark" (default) | "light"
data-roblox-fields"stats" (default) | "compact"
data-roblox-refreshSeconds between updates (0 = never)
