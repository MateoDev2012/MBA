SDKs & MCP server

Optional tools for servers and AI assistants. Neither is required — plain fetch works fine.

Node.js

Node.js SDK

Install

npm install roblox-stats-sdk

Source: extras/sdk/ in the repo.

Configure

// Optional: point at your own deployment
process.env.ROBLOX_BASE_URL = 'https://your-domain.com';

// Optional: API key for higher rate limits
process.env.ROBLOX_API_KEY = 'Made by MoonlightStudios';

Or pass options directly to methods.

All methods

MethodEndpointDescription
getGame(id)GET /games/{id}Full game data
getGameQuick(id)GET /games/{id}/quickLightweight version
batch(ids)GET /games/batchUp to 50 games at once
resolveUrl(url)GET /resolveURL → universeId
search(query, opts)GET /searchSearch games by name
trending(opts)GET /trendingMost played games now
getGamePasses(id, opts)GET /games/{id}/game-passesPasses with optional prices
getBadges(id)GET /games/{id}/badgesGame badges
getDeveloper(id)GET /games/{id}/developerCreator + group info
getGroupGames(id, opts)GET /groups/{id}/gamesGames by group
getUserGames(id, opts)GET /users/{id}/gamesGames by user
getFields()GET /fieldsAll placeholder names
render(opts)POST /renderFill template for one game
renderMulti(opts)POST /render/multiFill template for many games

Usage example

import { getGame, search, trending } from 'roblox-stats-sdk';

// Point at your own deployment
const game = await getGame(994732206);
console.log(game.name, game.playing, game.ratings.upVotes);

const results = await search('Blox Fruits', { limit: 5 });
const trendingGames = await trending({ limit: 10, includeMedia: true });

The SDK unwraps { ok, data } — methods return data directly. It reads ROBLOX_API_KEY from env automatically.

AI

MCP Server

The MCP server exposes the API to AI assistants (Claude, Cursor, etc.) over the Model Context Protocol.

# Run with your API key for higher limits
ROBLOX_API_KEY=Made by MoonlightStudios \
  node extras/mcp/server.js

Available tools

ToolDescription
get_roblox_gameFull game data by universeId
search_roblox_gamesSearch games by name
resolve_roblox_urlConvert Roblox URL to universeId
get_roblox_game_passesGame passes with optional prices
get_roblox_badgesGame badges
get_roblox_trendingMost played games right now
get_roblox_creator_gamesGames by group or user
fill_roblox_templateRender HTML template with live data
list_roblox_fieldsAll valid placeholder names
 
# Configure for Claude Desktop (claude_desktop_config.json)
{
  "mcpServers": {
    "roblox-stats": {
      "command": "node",
      "args": ["path/to/extras/mcp/server.js"],
      "env": { "ROBLOX_API_KEY": "Made by MoonlightStudios" }
    }
  }
}

Source: extras/mcp/server.js. Reads ROBLOX_API_KEY from env automatically.
