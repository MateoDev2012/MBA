Overview

What this is

MoonBlox reads Roblox's public game APIs and hands you the numbers in two shapes: as {{placeholders}} a script tag fills in, or as JSON you fetch yourself. Same data, same cache, same envelope — { "ok": true, "data": … } — whichever side you stand on.

For web pages

Drop in roblox-stats.js, write {{playing}} or {{likes}} where the number goes. No code, no fetch, no framework. The autofill rules are one page.

For code

Plain GET endpoints with open CORS, from browser, server, Python, PHP, anything. Start at endpoints, check the shape at live response.

Free to use, badge rule for the widget. The ready-made card keeps a small MBA · Made by Moonlight Studios credit — that is the only condition. Direct JSON calls need no badge. Details on legal and pricing & limits.

Quick start

Start here

Thirty seconds, in order. Each step is one page.

  1. Quick start. One script tag, your game's universeId, live numbers. Try 994732206 (Blox Fruits).
  2. The 20 stat names. What you can write in {{braces}}: playing, likes, visits, creator, and the rest.
  3. All 15 endpoints. Full game, quick, batch, search, trending, render — the complete JSON surface.
  4. Live response tester. Run any endpoint in the browser and see the exact JSON before you write code.
