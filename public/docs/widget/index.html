Ready-made card widget

Two lines instead of a layout. Put an ID in an empty

and get a complete card with banner, logo, stats, and link.

Basic

Minimal setup

<div data-roblox-game="994732206"></div>
<script src="https://ms-mba.up.railway.app/roblox-stats.js"></script>

Renders a complete card with banner, logo, game name, creator, playing count, and likes.

Customization

Custom styling

The widget uses CSS custom properties. Override them in your stylesheet:

your.css css
.rbxw-card {
  --rbxw-fg: #your-text-color;
  --rbxw-dim: #your-dim-color;
  --rbxw-live: #your-live-color;
  max-width: 400px;  /* or any width */
  border-radius: 12px;
}

.rbxw-card .rbxw-title { font-family: 'Your Font', sans-serif; }

All widget classes are prefixed with .rbxw- so they never leak into your page or get overridden by your styles.
