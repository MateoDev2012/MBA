Auto-fill rules

The script finds placeholder names, fetches data once per game, and writes values into your page. No framework, no build step, works on any host including GitHub Pages.

Syntax

Placeholder syntax

You writeYou get
{{playing}}Auto-abbreviated when it reads better: 245.4K
{{playing:raw}}Exact number: 245412
{{playing:short}}Always abbreviated: 245.4K
{{playing:full}}Never abbreviated: 245,412
{{thumbnail:url}}Escaped for src="…"
{{994732206:playing}}Inline game ID — uses specific game

For images use data-rbx-set, not src="{{thumbnail:url}}". A literal src makes the browser request the placeholder text before the script runs, leaving a 404 in the console on every page load.

Attributes

Binding & Attribute syntax

AttributePurposeExample
data-rbx-bind="playing"Sets element's text content
data-rbx-bind="994732206:playing"Sets text from specific game
data-rbx-set="src=thumbnail:url"Sets attribute when URL is real
data-rbx-set="src=994732206:thumbnail:url"Sets attribute from specific game
data-rbx-set="href=url|title=name"Multiple attributes at once

For images always use data-rbx-set, not src="{{thumbnail:url}}". A literal src makes the browser request the placeholder text before the script runs, leaving a 404 in the console on every page load.

Scopes

Multiple games on one page

Put data-rbx-game on any element — it owns the placeholders inside it. Nested scopes work: a card for game B inside a page about game A keeps its own numbers.


  
{{name}}

  
{{playing}} players

  

    
{{name}}: {{playing}}

Global fallback: Set window.RBX_GAME_ID = '994732206' before the script loads, and placeholders work globally without any data-rbx-game on the body.

A binding with no data-rbx-game ancestor is intentionally never filled. Otherwise an element outside every scope would still get filled, and you'd have no way to write the literal text {{playing}} in a tutorial or example.

Inline IDs

Inline game IDs

Reference a specific game's field directly in any placeholder, bind, or set attribute — no scope needed. Format: {{gameId:field}} or {{gameId:field:mode}}.

SyntaxMeaning
{{994732206:playing}}Blox Fruits player count
{{1686885941:visits:raw}}Brookhaven exact visits
{{994732206:thumbnail:url}}Blox Fruits logo URL (escaped)
data-rbx-bind="994732206:playing"Bind specific game's field
data-rbx-set="src=1686885941:thumbnail:url"Set attribute from specific game

Each inline game ID triggers one request, cached and shared. Perfect for comparison tables, leaderboards, or showing related games without wrapper scopes.

Options

Auto-fill options

Set on any element with data-rbx-game (including body or a wrapper).

AttributeValuesDefault
data-rbx-refreshSeconds between updates0 (never)
data-rbx-gameUniverse IDRequired if no global

Global config (set BEFORE script loads)

<script>
  window.RBX_GAME_ID = '994732206';  // Default game for all placeholders
</script>
<script src="https://ms-mba.up.railway.app/roblox-stats.js"></script>

Or use the config object:

<script>
  window.RobloxStatsConfig = {
    gameId: '994732206',
    apiBase: 'https://your-domain.com'  // Optional: custom API endpoint
  };
</script>
<script src="https://ms-mba.up.railway.app/roblox-stats.js"></script>

Typos are reported, not hidden. Write {{playng}} by mistake and you get a warning in the console naming the bad field, rather than a blank box. The authoritative list is /api/v1/fields.
