Good to know

The things that surprise people, stated up front.

Concept

Active players vs. visits

playing is players connected right now and changes constantly. visits is the all-time total since the game was created. They are not comparable — don't divide one by the other.

Timing

Data is not perfectly real-time

Roblox's own API lags: playing is usually 10 to 30 seconds behind the Roblox website. Do not treat it as an exact counter for anti-cheat, financial decisions, or anything where being off by 30 seconds matters.

IDs

universeId vs placeId

They are different things. A URL ending in /Place carries a placeId; use /api/v1/resolve if you're unsure and the API converts it for you.

Performance

About the cache

Player counts are cached for 30 s and votes for 5 min, so two calls in a row can return the same number. That is on purpose: it's what lets this API stay free without hitting Roblox's rate limits.

Optional

Do you need an API key?

Not with the script tag: roblox-stats.js already sends one for you, so there's nothing to configure. If you're calling JSON endpoints yourself, ignore this too: with no keys configured every request is welcome, up to RATE_LIMIT_MAX (120/min) per IP. Only send one if you run your own deployment and have turned keys on, in the X-API-Key header and never a query parameter: those leak into access logs and into the Referer of every link on your page. Check what a key is worth with /api/v1/keys/me.

The rule

The credit badge is the part that matters

The API key is a rate limit you can tune; the small MBA · Made by Moonlight Studios badge is what actually keeps this free, because deleting it switches the file off. It links to the studio's site, so leaving it in place is also how people find out who made this.

Removing or hiding the badge (even with CSS display:none) stops the script. The file checks that the badge is present, visible, and linked before it writes any number.

Roblox API

Roblox's own limits

Roblox only publishes limited list endpoints. limit on group games only accepts 10, 25, 50 or 100 — anything else is a 400. There is no public list of a game's servers, so player counts are the closest thing available. Search withholds creatorName/creatorId; use /games/{id} if you need it.
