Errors & rate limits

Every failure uses the same envelope: { "ok": false, "error": { "code", "message" } }.

Reference

Error codes

CodeHTTPMeaning
INVALID_ID400ID in path is not a positive number
INVALID_QUERY400Query parameter missing or out of range
UNKNOWN_FIELDS400Placeholder name doesn't exist; message lists bad ones
MISSING_KEY401Deployment requires API key, none sent
INVALID_KEY403Key not configured, or domain lock mismatch
RATE_LIMITED429Too many requests; retry after Retry-After seconds
NOT_FOUND404No game, group, user, or route with that ID
UPSTREAM_ERROR502Roblox is down/slow/refusing; retry in seconds
INTERNAL_ERROR500Bug on our side; message deliberately vague

All errors use the same envelope: { "ok": false, "error": { "code", "message" } }. This makes it easy to handle every failure with one code path.

Optional

API keys

Out of the box no key is needed. Set API_KEYS in .env to enable.

.env dotenv
API_KEYS=Made by MoonlightStudios
API_KEY_MODE=optional
RATE_LIMIT_ANON_MAX=30
RATE_LIMIT_KEYED_MAX=600

Modes: off | optional | required. Default: optional.

Send key in header (not URL)

fetch('https://your-domain.com/api/v1/games/994732206', {
  headers: { 'X-API-Key': 'Made by MoonlightStudios' }
})

Also accepts Authorization: Bearer and ?key= (but URL leaks into logs/Referer).

Domain locks & multiple keys

# Multiple keys, one with domain lock
API_KEYS=Made by MoonlightStudios;partner-key:AcmeSite:yoursite.com,acme.dev

# Each entry: key[:Name[:domain1,domain2...]]
# Semicolon-separated

A key is not a secret. It sits in plain text inside roblox-stats.js — anyone can read it. What it buys: rate limit you control, revocation, domain locks. It does NOT make data private. The credit badge in roblox-stats.js is what keeps this free.

Check your quota: GET /api/v1/keys/me tells you your current key, mode, limit, and usage count.

Headers

Rate limit headers

Every response includes these headers (exposed via CORS so browsers can read them):

HTTP/1.1 200 OK
Access-Control-Expose-Headers: X-RBX-Key, RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset, Retry-After
RateLimit-Limit: 120
RateLimit-Remaining: 119
RateLimit-Reset: 60
X-RBX-Key: anonymous

Use RateLimit-Remaining to pace your requests. On 429, respect Retry-After.
