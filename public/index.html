Fifteen endpoints

All GET except two. One envelope, always.

Full reference →
GET/games/{universeId}

Everything about a game in one call.

GET/games/{id}/quick

No media. For cards and listings.

GET/games/batch?ids=

Up to 50 games in one request.

GET/trending?limit=20

Most played right now.

GET/resolve?url=

Any Roblox URL to its universeId.

POST/render

Fills placeholders in an HTML string.
