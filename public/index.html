Start here

One file, one script tag, done

You do not need to study this API to use it. Copy roblox-stats.js into your project, add the tag below, and write the name of any stat wherever you want it. That is the entire setup.

index.html html
<body data-rbx-game="994732206">

  <h2>{{name}}</h2>
  <p>{{playing}} players right now · {{likes}} likes</p>
  <img data-rbx-set="src=thumbnail:url">

  <script src="https://YOUR-DOMAIN.com/roblox-stats.js"></script>

Prefer plain JSON?

Everything the file above builds is also one plain HTTP call, with no library and no key. The id below is Blox Fruits.

Reference

Everything it can answer

Fifteen endpoints, all GET except the two render ones. Every response uses the same envelope: { "ok": true, "data": … }.

GET/api/v1/games/{universeId}

Everything important about a game in one call: data, owner, votes, favorites, thumbnail, banners and media.

GET/api/v1/games/{universeId}/quick

Lightweight version without heavy media. Ideal for cards, listings and widgets where payload size matters.

GET/api/v1/games/batch?ids=1,2,3

Up to 50 games in a single request. For listings: do not make 50 calls, make one.

GET/api/v1/trending?limit=20

The most played games right now, sorted by live player count. A popularity ranking, not a curated chart.

GET/api/v1/resolve?url={url}

Converts any Roblox URL to its universeId, including place URLs.

POST/api/v1/render

Fills {{placeholders}} in an HTML string with live data. Works from a server or the browser.

The one rule

Leave the credit badge in

The small MBA · Made by Moonlight Studios badge that comes with roblox-stats.js is what keeps this free. Delete it, or hide it with CSS, and the file stops filling in numbers. It links to the studio's site, so leaving it in place is also how people find out who built this.

There is no API key to leak, no account to close, no per-request billing. The badge is the deal.
