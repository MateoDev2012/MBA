The one rule

Keep the badge, keep the API

The free tier is not a trial. It costs money to run — a server, a domain, and the request budget that keeps the numbers honest. What pays for it is one line of credit.

What the badge actually does

roblox-stats.js draws a small MBA · Made by Moonlight Studios badge and links the studio’s name to the studio’s site. It then checks that the badge is still in the page, visible and connected, before it writes any number into it. Remove the element, empty its text, or cover it with display:none, and the script stops.

That is not a legal trick. It is the whole mechanism, in about forty lines of readable JavaScript you can inspect with view-source.

Running your own copy? Then the badge is a request, not a lock. The enforcement lives in the browser file, which is yours to read and edit. The terms ask you to keep the credit visible, and in exchange you get an API with no dependency on this server. Nothing else changes.

No account needed

What is not behind anything

Spelled out, because “free” usually hides a list somewhere.

No signup, no email

There is no user table, no cookie, no tracker and no analytics on this site. Nothing to fill in.

No API key to obtain

With no keys configured every request is welcome, up to RATE_LIMIT_MAX per IP.

No rate limit per feature

One limit covers everything. There is no “call this endpoint 10 times a day” tier.

No attribution required for JSON

Calling /api/v1/… from your own code needs no credit. The badge belongs to the ready-made file and the card widget.

No CORS wall

Any origin may read the responses, from a browser, without a proxy. That is deliberate.

No expiry

No trial that turns into a paid plan, no request quota that resets monthly, no seat count.

The actual numbers

Limits as they are

Configurable on a self-hosted copy. These are the defaults.

LimitValueWhy
Requests per minute, per IP120Enough for a page of cards, not enough to be a free CDN.
Requests per minute, per valid key600So a server that caches properly is not punished for it.
Games per /batch call50One request instead of fifty is the point of the endpoint.
Games per /trending call20Each extra game is another request to Roblox.
Template size, POST /render200 KBIt renders strings, it does not host your page.
Player count cache30 sRoblox itself lags 10–30 s, so a shorter TTL buys nothing but quota.
Vote cache5 minLikes move slowly; asking more often is pure waste.

Check your own quota at any time. Every response carries RateLimit-Limit, RateLimit-Remaining and RateLimit-Reset, and GET /api/v1/keys/me tells you how the server is treating you right now.

Questions

Frequently asked

Can I use this commercially, for a real product?

Yes. The terms are on the legal page: use it commercially, monetise your own site, no per-request fee to anyone. The two things asked of you are to leave the credit badge visible when you use roblox-stats.js, and not to hammer the endpoints.

What exactly counts as removing the badge?

Deleting the badge element, emptying the studio name out of it, breaking the link, covering it with CSS, or repointing the link somewhere that is not the studio’s site. The file checks for all of those before it fills anything in. The honest summary: if someone opening view-source cannot see the credit, the badge is not there.

Do I need a key if I only want the JSON?

No. A key only exists on deployments where somebody configured one, and it is documented as public, not secret — it buys a higher rate limit, revocation and domain locks. It does not make your copy of the data private, and it is not what funds this.

Will the public instance stay up?

No promise, and nobody should build a business on somebody else’s free server. The cache, the rate limits and the fact that the whole thing is one small Node app are all there so that running your own copy takes an afternoon and costs a few dollars a month.

Is the data legal to redistribute?

It comes from Roblox’s public APIs, and the short answer is that reading a public page and publishing a number is not the same as republishing Roblox’s assets. Do not mirror Roblox thumbnails or banners as if they were yours, and do not use Roblox marks in your branding. The legal page has the version I would stand behind.

Can I report a bug or request an endpoint?

Please do — the contact address is on the legal page. The most useful reports are an id that returned nothing and the endpoint that was used.
