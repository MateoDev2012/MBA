One file, real data

Everything below is loaded by a single <script> tag pointing at roblox-stats.js. There is no other JavaScript on this page doing the filling — the only numbers you see are the ones the file wrote.

1

Write the stat name, get the number

This is the whole idea. No code, no fetch, no framework.

<h2>{{name}}</h2>
<p>{{playing}} players right now · {{likes}} likes</p>

by {{creator}}

{{description}}

Playing{{playing}}
Likes{{likes}}
Visits{{visits}}

2

Mixed with your own text

<p>Right now <b>{{playing:raw}}</b> people are playing {{name}}.</p>

Right now {{playing:raw}} people are playing {{name}}. It has been visited {{visits:raw}} times, which reads as {{visits}} in short form.

3

Attributes and the binding syntax

<span data-rbx-bind="playing"></span> players
<img data-rbx-set="src=thumbnail:url">

<!-- works too, but the browser requests the placeholder text first: -->
<img src="{{thumbnail:url}}">

players — the binding syntax.

← set with data-rbx-set, so nothing is fetched until the URL is real.

5

Or take the card as it is

Two lines instead of a whole layout. Put an id in a <div> and leave it empty.

<div data-roblox-game="994732206"></div>
<script src="https://YOUR-DOMAIN.com/roblox-stats.js"></script>

Default — banner, logo and stats

Compact — no banner, no visits

Light theme

Auto-refreshing every 30 s

AttributeWhat it does
data-roblox-gameThe universeId of the game. Required.
data-roblox-theme"dark" (default) or "light".
data-roblox-fields"stats" (default) or "compact".
data-roblox-refreshSeconds between updates. 0 means never.
6

A typo shows up instead of hiding

Open the console: the bad field name is logged. Nothing is left blank without explanation.

<span data-rbx-bind="playng"></span>   <-- wrong name

← left empty and logged, because a blank box is impossible to debug.

GET /api/v1/fields is the authoritative list of names.
